$\lim_{x \to 1} \frac{(x-1)(x+1)(x^2+1)}{(x-1)(x^2+x+1)} = \lim_{x \to 1} \frac{(x+1)(x^2+1)}{x^2+x+1} = \frac{(1+1)(1^2+1)}{1^2+1+1} = \frac{2 \cdot 2}{3} = \frac{4}{3}$។

តាមរូបមន្តដឺម័រ (De Moivre's Theorem)៖
$z = \cos\left(6 \cdot \frac{\pi}{6}\right) + i\sin\left(6 \cdot \frac{\pi}{6}\right) = \cos\pi + i\sin\pi$។
ដោយសារ $\cos\pi = -1$ និង $\sin\pi = 0$ នាំឱ្យ $z = -1 + 0 = -1$។
គណនាតម្លៃបន្សំ៖ $C(8, 2) + C(8, 6)$ (៥ ពិន្ទុ)
💡 ដំណោះស្រាយលម្អិត៖
ប្រើលក្ខណៈបន្សំ $C(n, p) = C(n, n-p)$ នាំឱ្យ $C(8, 6) = C(8, 8-6) = C(8, 2)$។
គណនា $C(8, 2) = \frac{8 \times 7}{2 \times 1} = 28$។
ដូចនេះ $C(8, 2) + C(8, 6) = 28 + 28 = 56$។
គេបោះគ្រាប់ឡុកឡាក់ស្មើទម្ងន់មួយគ្រាប់ចំនួន ១ ដង។ រកប្រូបាបដែលគ្រាប់ឡុកឡាក់ចេញ«លេខជាតួចែកដាច់នៃ ៦»។ (៥ ពិន្ទុ)
💡 ដំណោះស្រាយលម្អិត៖
- លំហសំណាក៖ $S = \{1, 2, 3, 4, 5, 6\} \implies n(S) = 6$។
- ព្រឹត្តិការណ៍ $A$ ចេញលេខជាតួចែកដាច់នៃ ៦៖ លេខទាំងនោះមាន $\{1, 2, 3, 6\} \implies n(A) = 4$។
- ប្រូបាប៖ $P(A) = \frac{n(A)}{n(S)} = \frac{4}{6} = \frac{2}{3}$។
